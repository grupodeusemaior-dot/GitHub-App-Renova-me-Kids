RENOVA-ME KIDS — AJUSTE DE TEXTO JUSTIFICADO

Arquivos incluídos:
- style.css: altera exclusivamente o alinhamento dos parágrafos de leitura para justificado.
- service-worker.js: somente atualiza a versão do cache para que o navegador receba o CSS novo.

Como aplicar pelo GitHub Web:
1. Extraia este ZIP.
2. Abra o repositório Renova-me Kids no GitHub.
3. Clique em Add file > Upload files.
4. Envie style.css e service-worker.js para a raiz do repositório, substituindo os existentes.
5. Clique em Commit changes.

Nenhum outro arquivo deve ser alterado.
Após a publicação, feche e abra novamente o aplicativo. Se necessário, abra o site no navegador e atualize a página.

Todas as demais funções e aparências do aplicativo foram preservadas.
